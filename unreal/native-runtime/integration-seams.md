# Remaining local integration

This source compiles; it is not connected to the current website or packaged character scene. Keep production rendering unchanged until the real runtime and hosting checks pass.

1. **Own the native streamer and control server.** Set both Pixel Streaming default-start settings to false before module initialization. Reject existing streamers. Bind a new Node HTTP server exclusively to `127.0.0.1:49081`, then call `attach(server, WebSocketServer, freshNativeToken)` from `bridge/control-gateway.cjs`. Reuse the already pinned local SDK dependency. Confirm the bind before launching the native child; pass the native token only in its environment. Imports do not start listeners. The launcher owns normal child completion and server shutdown.

2. **Add explicit browser control transport.** The local embedded page on port 49080 must allow only the exact loopback control HTTP/WebSocket endpoints in its CSP. Preserve its existing parent-origin, source and nonce checks. `connectControl({onOpen, onResponse, onClose})` returns `send(text)`, `close()`, `isOpen()` and a `connected` setup promise. `connected` does not prove authorization or media readiness: `onOpen` fires only after the authorized gateway's `READY`. Send the bounded original protocol JSON through `send`, replacing SDK UIInteraction for this preview. Disable stock browser input as well; the native null handler remains the security boundary.

3. **Require actual rendered readiness.** An authorized control socket is insufficient. Require the native state acknowledgment for the exact play request and two newly presented video frames before exposing ready controls. Validate that the official client can receive video without input protocol/settings replies. Do not synthesize ready from SDK data-channel connection or time elapsed.

4. **Bind a real isolated character scene.** The component needs the exact body, face, outfit, idle/walk assets and five explicit camera bindings. Author a new scene in a separate derived project; preserve the accepted character assets. Disable any competing autoplay sequence in that new scene. Whole-gi color changes set `BaseColor` and `AccentColor` together; `BeltColor` is independent. Unsupported hairstyles, stripes and separate jacket/pants colors are not advertised. The existing single-character catalog must stay separate from combat moves.

5. **Exercise the actual runtime.** Verify pause/play, seek/reset, speed, camera, gi/belt colors, exact progress observations, stale sessions, disconnect and manual reconnect against visible frames. Confirm hostile RTC input/Multiplexed/Command/helper frames have no app or engine effect. Verify that detach pauses and cleanup restores the prior scene. Compile and cook a separate Game target before claiming packaged receiver behavior.

6. **Keep paired gameplay and public hosting separate.** Arena/Training needs two actual character bindings and validated paired clips with contact/choreography checks; idle/walk cannot substitute for jiu-jitsu. Public Unreal also needs an approved GPU/session host, authenticated session allocation, HTTPS/WSS and controlled lifecycle. The local gateway is not that public service, and this source check-in makes no deployment change.
