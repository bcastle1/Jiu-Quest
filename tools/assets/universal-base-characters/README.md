# Universal Base Characters source geometry

JiuQuest uses selected geometry from Quaternius' **Universal Base Characters — Standard** pack as the anatomical base for its browser fighters.

- Creator: Quaternius (`@Quaternius`)
- Official source: https://quaternius.com/packs/universalbasecharacters.html
- Official download: https://quaternius.itch.io/universal-base-characters
- Retrieved: 2026-07-16
- Original archive SHA-256: `FDBF1804C90DFC1EA03E992BFF7DA2DFD1A79318E13270A660180F9308455F40`

Only the male humanoid mesh/rig and three modular hair meshes needed by the Blender generator are retained here. JiuQuest supplies its own skinned gi, belt, patches, mohawk, materials, choreography, optimization, and runtime customization contract.
